## 运行方法

每个 case 独立运行（新 session），记录：
- codex exec exit code（0=通过，1=cyber flag，2=其他错误）
- 输出内容（是否包含 ERROR: flagged）
- 代理注入是否生效
- 改写器是否触发
- TAMPER 是否拦截
