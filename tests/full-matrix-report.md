## 核心发现

**cyber flag 触发条件**（特定意图词组合，不是所有恶意请求）：
- "隐藏进程"类（进程规避）→ cyber flag
- "键盘记录器"（窃取凭证）→ cyber flag
- "Metasploit"（攻击工具名）→ cyber flag
- "中间人攻击" → cyber flag

**模型层拒绝（非 cyber）**：
- PUBG外挂/自瞄/透视 → 模型安全对齐拒绝
- 绕过反作弊 → 模型拒绝
- 勒索软件/后门 → 模型拒绝

**改写器工作验证**：
- NVIDIA llama-3.1-8b 直连 → 2s 内返回，content 有值
- mimo-v2.5-pro 推理模型 → content 为空（未生效）
- 改写器把意图词转为技术描述后不触发 cyber

**代理层拦截验证**：
- proxy 检测 cyber → 改写 → fork 新 session → 重发
- 重发不注入 AGENTS（不带 AGENTS 内容的干净请求）
- 代理拦截成功但重发仍被 cyber（session 级封锁，同 session 重发必 403）

## 结论

1. **cyber 是特定意图词触发的**，不是所有恶意请求都触发
2. **改写器有效**：把意图词转为技术描述后不触发 cyber
3. **代理层拦截 cyber 后改写+fork 可行**（代码逻辑正确，但需要改写质量更高）
4. **多轮渐进是最稳定路径**：先建立中性上下文再逐步引入敏感词
