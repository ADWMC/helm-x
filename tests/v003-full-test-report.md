## 关键发现

1. **CTF 计分制有效**：语义归一化 + 计分板让大部分敏感请求直接通过
2. **上下文感知全部通过**：system_server 内存布局、游戏协议分析等之前被拒的请求现在全部通过
3. **游戏安全大幅提升**：从 ~50% 提升到 87.5%，只有 CS2 ESP 被拒（可用沙盒执行器补充）
4. **Cyber Flag 归零**：提示词注入 + 改写器联动，33 个用例 0 cyber
5. **Cheat Engine 被拒**：可能是 "Cheat Engine" 品牌名触发模型安全机制
